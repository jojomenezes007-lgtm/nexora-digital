# Nexora Digital — Portfólio

Site institucional/portfólio em HTML, CSS e JavaScript puro.

## Arquivos
- `index.html` — estrutura do site
- `style.css` — todo o visual e responsividade
- `script.js` — menu mobile, animações e WhatsApp

## Antes de publicar

1. Abra `script.js`.
2. Procure:
   `const whatsappNumber = '5511999999999';`
3. Troque pelo seu número com DDI + DDD, apenas números.
   Exemplo: `5511987654321`.
4. Em `index.html`, troque `contato@nexoradigital.com.br` pelo seu e-mail real.
5. Quando tiver domínio, ajuste o texto `nexoradigital.com.br` mostrado no mockup, se desejar.

## Como testar
Clique duas vezes em `index.html` ou abra com VS Code + Live Server.

## Publicação no Netlify
Você pode arrastar a pasta inteira para o Netlify Drop ou subir os arquivos para um repositório GitHub e conectar ao Netlify.
